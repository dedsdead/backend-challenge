## Conventions

- One file per user-facing feature, named after the feature.
- Stable headings: Overview, User Flow, Components, State & Data Flow, Error/Empty/
  Loading States, Testing.
- Generated/maintained via `/pwf-doc feature <name>` and post-work doc maintenance.
- API contracts referenced from [../integrations.md](../integrations.md).
